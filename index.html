Comment ça marche

1. Choisir les personnes
Tu peux modifier les noms et ajouter une photo.
2. Coche les tâches
Quotidiennes ou hebdomadaires.
3. Fais le tirage
L’application répartit les tâches au hasard.
4. Donne les points
Quand la tâche est finie, les points s’ajoutent.

Profils enfants

Chaque enfant peut avoir un nom et une photo. Les photos sont sauvegardées dans le navigateur.
